# Martin's Software Development Portfolio

A personal portfolio website built from scratch with HTML, CSS and JavaScript.

## Features

- Responsive design
- Multi-page portfolio
- Dark/light mode
- Project detail pages
- Skills and experience sections
- GitHub Pages friendly
- No external framework required

## Pages

- `index.html` — Home
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects
- `contact.html` — Contact
- `projects/` — Individual project pages

## Before publishing

Replace:

- Placeholder biography text
- Email address
- GitHub URL
- LinkedIn URL
- Project descriptions
- Project repository links
- Skill percentages
- Any placeholder images/content

## GitHub Pages

Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository settings.

This project was written specifically as a starting point for a personal student portfolio.
