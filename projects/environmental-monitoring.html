Real-Time Environmental Monitoring

A real-time environmental monitoring system using a Raspberry Pi with a Sense HAT and an Android mobile application.

Real-Time Environmental Monitoring
Technologies
PythonJavaAndroidRaspberry PiSense HATWebSocket

Overview

This project is a real-time environmental monitoring system that uses a Raspberry Pi and Sense HAT to collect environmental data. The data is transmitted to an Android application where users can monitor readings such as temperature, humidity and pressure.

My contribution

I worked on the Android application and the communication between the Raspberry Pi and mobile application. I implemented the display of real-time sensor readings and worked with the data received from the Raspberry Pi through WebSocket communication.

What I learned

I learned how to work with real-time data and communication between different devices. The project helped me develop my understanding of Raspberry Pi, Android development, WebSocket communication and displaying changing sensor data in a mobile application.
