Wage After Tax Calculator

A responsive web application for estimating take-home pay using Irish tax and deduction rules.

Wage After Tax Calculator
Technologies
JavaScriptHTMLCSSGitHub Pages

Overview

This project was created to turn wage and tax calculations into a simple web interface where users can enter their working information and receive an estimated result.

My contribution

I developed the user interface and implemented the JavaScript calculations used to process the user's wage information. I also worked on input handling and validation to ensure that the calculator could handle different user inputs correctly.

What I learned

I developed my understanding of JavaScript logic, handling user input, performing calculations and presenting results clearly through a web interface. I also gained experience deploying a web application using GitHub Pages.
