Inventory Management System

Inventory Management System
Technologies
JavaJava SwingMySQLJDBCJUnitJenkinsSonarCloudGitHub

Overview

This project is a Java-based inventory management system designed for managing products, suppliers, sales and stock within a clothing business. The system uses a MySQL database to store and manage the application's information.

My contribution

I worked as part of a development team on the application, contributing to the user interface, database functionality and application features. I also worked with GitHub for version control and contributed to testing and improving the quality of the software.

What I learned

I gained practical experience working as part of a software development team and learned more about MVC architecture, database integration, testing and version control. I also gained experience using tools such as JUnit, Jenkins and SonarCloud as part of the software development process.
