Smart Greenhouse

An Android and ESP32 project using MQTT to monitor sensors and control greenhouse equipment.

Smart Greenhouse
Technologies
JavaAndroidESP32MQTTArduinoJSONUART

Overview

This project is an IoT-based smart greenhouse system designed to monitor environmental conditions and control greenhouse equipment. An ESP32 collects sensor data such as temperature, humidity, soil moisture and light levels, while an Android application allows the user to monitor the system and control connected devices.

My contribution

I developed the Android application and worked with the ESP32-based hardware and MQTT communication. I implemented real-time sensor monitoring, manual and automatic control of the greenhouse devices, and communication between the Android application and the ESP32.

What I learned

I learned how mobile applications can communicate with physical devices using MQTT and how sensor data can be transferred and processed in real time. I also gained experience working with ESP32 hardware, connected devices and designing a system where software and hardware work together.
